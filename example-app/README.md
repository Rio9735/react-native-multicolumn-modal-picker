# Example app

This app demonstrates `react-native-multicolumn-modal-picker` in a real React Native app.

## 1. Download the example app

Open a terminal (Command Prompt (cmd), PowerShell, macOS Terminal, or Linux terminal) and run the following commands **in order**.

These commands download only the `example-app` directory from the repository:

```bash
git clone --depth 1 --no-checkout https://github.com/Rio9735/react-native-multicolumn-modal-picker.git
cd react-native-multicolumn-modal-picker
git sparse-checkout set --no-cone /example-app/
git checkout
cd example-app
```

## 2. Install dependencies

Run:

```bash
npm install
```

## 3. Start the app

Run:

```bash
npm start
```

Then launch the app on a simulator or physical device from the Expo UI.

## Package version

The example app uses a published version of `react-native-multicolumn-modal-picker` from npm.

To test a different published version, update the dependency in `package.json` and run:

```bash
npm install
```
